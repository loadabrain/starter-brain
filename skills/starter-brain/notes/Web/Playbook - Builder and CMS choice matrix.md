# Playbook - Builder and CMS choice matrix

> [!summary] TL;DR
> Start from four questions: who edits, does it sell online, does the code have to be owned, and where is the data.
> Each option cell cites its entity note; cells marked (open) were not verified this session.
> No option wins on every row: the matrix shows trade-offs, not a ranking.

## Use
Fill one column per shortlisted option before recommending it. Every price is as listed on the vendor page on the date in its note; re-check before quoting.

## Decision questions
1. Who edits the site after launch: the client (visual editor) or a developer?
2. Does it sell online? If yes: payment methods (Bancontact, iDEAL) and fees.
3. Must the code be owned or exported? If yes: check the export and licence terms first.
4. Where is the data hosted? Check the vendor's own statement; many pages state none.

## Rules of thumb (opinion, not sourced)
- Client edits every week and does not code: visual editor or WordPress block theme (WordPress block themes).
- Sells online with local payment methods: check Bancontact and iDEAL support first (Bancontact).
- Code must be owned: start with platforms whose export terms are stated; AI builders need the terms read before the contract.
