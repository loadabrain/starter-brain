# Starter brain

42 short notes on the basics of sales, marketing, websites, brand and design, small-business finance and AI helpers. Your AI reads them before it answers and shows where it got each answer, with the date.

Works as a **Claude Code plugin**, as a plain **folder** any AI can read, and in **Obsidian**.

## Install as a Claude Code plugin
```
/plugin marketplace add loadabrain/starter-brain
/plugin install starter-brain@loadabrain
```
Then ask, for example: *"Using the starter brain, how should I price a service project? Show the sources."*

## Use as a folder (or in Obsidian)
1. Download or clone this repo.
2. Optional: open it in Obsidian ("Open folder as vault").
3. Open your AI in the folder (with Claude Code: type `claude` in the Terminal). It reads the rules in `CLAUDE.md` (other AI tools: `AGENTS.md`).

## What's inside
- `skills/starter-brain/notes/`: 42 notes in 6 fields. Each has a summary, dated sources and a `confidence` value.
- `skills/starter-brain/SKILL.md`: the rules your AI follows and a list of every note.
- No scripts, hooks, MCP servers or network calls. Nothing runs on install.

## Good to know
- Not legal or financial advice. Notes on rules quote their sources and dates; check the current rules before you act.
