# Starter brain

42 short, sourced notes on the basics of sales, marketing, websites, brand and design, small-business finance and AI agents, plus one skill that makes Claude answer from them first, with each note's sources and dates.

Works as a **Claude Code plugin**, as a plain **folder for any AI agent**, and as an **Obsidian vault**.

## Install as a Claude Code plugin
```
/plugin marketplace add loadabrain/starter-brain
/plugin install starter-brain@loadabrain
```
Then ask, for example: *"Using the starter brain, how should I price a service project?"*

## Use as a folder or Obsidian vault
1. Download or clone this repo.
2. Optional: open it in Obsidian ("Open folder as vault").
3. Start your agent in the folder (`claude` for Claude Code). It reads `CLAUDE.md` / `AGENTS.md`.

## What's inside
- `skills/starter-brain/notes/`: 42 notes in 6 fields. Each has a summary, dated sources and a `confidence` value.
- `skills/starter-brain/SKILL.md`: the rules (Lite OS) and an index of every note.
- No scripts, hooks, MCP servers or network calls. Nothing runs on install.
